# Подготовка релиза

Использовать только при запросе релиза. Версию брать из сообщения пользователя (например, `1.3.0`). Если версия не указана или неоднозначна, запросить её, параллельно изучая историю. Все пути ниже — от корня репозитория. Соблюдать `AGENTS.md`.

1. Проверить рабочее дерево. Правки кода должны быть отдельными коммитами до релиза; не включать чужие или несвязанные изменения в релизный коммит.
2. Определить предыдущий релиз через `git describe --tags --abbrev=0` и изучить `git log <prev-tag>..HEAD --oneline`. Если тегов нет — изучить всю историю. Проверить, что тег `v<версия>` ещё не существует; существующий тег не перезаписывать.
3. Сформировать `RELEASE_NOTES.md` с заголовком `# v<версия>`:
   - Группировать по пользовательским фичам, а не коммитам.
   - Фичи и заметные улучшения описывать кратко, без деталей реализации.
   - Фиксы багов предыдущих версий давать одной строкой. Не включать баги, появившиеся и исправленные внутри текущего релиза.
   - Внутренние изменения объединять в одну строку; категории использовать, когда они помогают чтению.
   - Каждое утверждение сверять с итоговым кодом.
4. Обновить `versionMajor`/`versionMinor`/`versionPatch` в `app/build.gradle.kts`. `versionCode` и `versionName` вычисляются автоматически.
5. Прочитать `.agents/skills/scout-screenshots/SKILL.md` и выполнить генерацию и визуальную проверку скриншотов с новой версией.
6. Прочитать `.agents/skills/scout-verify/SKILL.md` и выполнить полный набор проверок. Если проверки или скриншоты недоступны, сообщить блокер и оставить подготовленные файлы для продолжения; не создавать релизный коммит/тег с непроверенным результатом.
7. Проверить diff и закоммитить только `RELEASE_NOTES.md`, `app/build.gradle.kts`, `.github/images/screenshots/` одним релизным коммитом. Не использовать `git add .`.
8. Создать локальный тег `v<версия>` и сообщить хеш коммита, тег и результаты проверок.

**Не пушить.** Пользователь пушит сам. Push тега запустит `.github/workflows/release.yml`, который публикует GitHub Release с APK. Публикация не входит в этот скилл.
