# Скриншоты README

Работать из корня репозитория по `AGENTS.md`. Подготовка эмулятора: `docs/agent-setup.md`. В PowerShell заменить `./gradlew` на `./gradlew.bat`.

Если работа добавляет самостоятельный экран Scout, включить его в раздел «Скриншоты» README в том же коммите: найти все перечни снимков, добавить e2e-тест с `@ReadmeScreenshot`, имя в `readmeScreenshotNames` в `app/build.gradle.kts`, полученный PNG, ссылку `<img>` с `alt` в `README.md`, запись в `.github/workflows/prepare-release.yml` и проверку списка в `scripts/planChecks.test.mjs`. Обновить перечень в этом скилле. Сохранить исходное разрешение PNG, если уменьшение делает текст или индикатор нечётким; размер в README задать через `width` у `<img>`. Прогнать генератор и новый e2e-тест несколько раз, затем открыть PNG и сверить видимые элементы с приложением.

1. Проверить `adb devices`: нужен подключённый эмулятор в состоянии `device`. Профиль: API 33, Pixel 4, WebView 101, образ `default` без Google Play. Если устройств несколько, выбрать нужный через `ANDROID_SERIAL`.
2. При подготовке релиза сначала должна быть обновлена версия в `app/build.gradle.kts`: экран настроек показывает `BuildConfig.VERSION_NAME`.
3. Запустить:

   ```sh
   ./gradlew :app:updateReadmeScreenshots
   ```

   Задача запускает классы из `app/src/androidTest/java/com/github/wrager/sbgscout/e2e/screenshots/`, фильтруя тесты по `@ReadmeScreenshot`, затем копирует PNG в `.github/images/screenshots/`. На обычный `connectedInstrAndroidTest` фильтр не влияет. Тесты сами устанавливают русскую локаль приложения и сбрасывают её после прогона.
4. Проверить `git status --short -- .github/images/screenshots/` и открыть изображения доступным инструментом просмотра: `game_loading.png`, `game_settings.png`, `settings.png`, `script-manager.png`. Проверить полный рендер без артефактов загрузки, русскую локализацию, отсутствие индикатора справа внизу на `game_loading.png` и сохранность надписи, кнопок и игровых этапов. Его ширина — 1080 px, остальные снимки — 360 px.
   При добавлении нового PNG включить его генератор и e2e-утверждения для ключевых элементов экрана. Состояние в тесте можно вызвать искусственно, но текст и штатные элементы на итоговом PNG должны выглядеть как в приложении. Для анимированного элемента проверить движение отдельным e2e-утверждением; форма одного кадра проверяется при просмотре PNG.
5. Оставить PNG в рабочем дереве. Скилл сам не создаёт коммит. В релизе скриншоты входят в общий коммит с версией и `RELEASE_NOTES.md`.

`settings.png` и `script-manager.png` показывают нативный UI. `game_loading.png` снимает экран загрузки игры на фикстуре `app-page-loading-screen-realistic.html`: разметка и тексты этапов из `refs/game/index.html` без стилей игры. `game_settings.png` использует mock-фикстуру `app-page-with-settings-content-realistic.html`, если нет локального snapshot. Задача `inlineGameSnapshot` подхватывает сохранённую HTML-страницу с каталогом `*_files/` из gitignored `refs/game/private/`. Публичный fallback должен сохранять заголовок «Настройки», секцию «Общее», язык, тему и строку Scout внутри кадра; отдельный функциональный тест принудительно проверяет его и при наличии snapshot. Для индикатора загрузки отдельный сценарий проверяет движение, дугу и пустой центр при незавершённом ресурсе страницы. Snapshot и приватные данные в Git не добавлять. Тесты обращаются только к локальному fake-серверу.

Если эмулятор или SDK недоступны, сообщить причину; не заменять генератор ручными снимками и не утверждать, что скриншоты обновлены.
